# Krug · Круг

**Истории, люди, обсуждения.**

Небольшой социальный блог с личными черновиками, публичными записями и лентой авторов.

Напиши историю, сохрани её в черновиках или опубликуй с фотографией. Читай
публичные записи, подписывайся на авторов и обсуждай их публикации. Интерфейс
адаптирован к компьютеру и телефону, поддерживает русский и английский языки.
Проект находится в разработке; заявлений о промышленной надёжности или масштабе нет.

### Стек и устройство

| Часть | Технологии |
| --- | --- |
| API | Python 3.14, FastAPI, Pydantic |
| Данные | PostgreSQL 15, SQLAlchemy, Alembic, встроенный полнотекстовый поиск |
| Фоновые задачи | Celery, Redis, SMTP; Mailpit для тестовой почты |
| Интерфейс | Обычные HTML, CSS и JavaScript, без этапа сборки |
| Выполнение | Docker Compose или Podman на Linux |

API находится в `backend/`, интерфейс — в `frontend/`. Их обслуживает один
веб-сервис; приложение открывается по `/app`. Токены хранятся в sessionStorage
вкладки, выход отзывает все сессии аккаунта.

Описание [продукта](PRODUCT.md), [системы дизайна](DESIGN.md),
[API](docs/api.md) и [развёртывания](docs/development.md) дополняет это руководство.
Результаты CI доступны в [GitHub Checks](https://github.com/wsersigma228/krug/actions/workflows/check.yml).

## Что реализовано

- Регистрация, вход, подтверждение email, восстановление пароля и выход со всех устройств. Email необязателен, но без него восстановление доступа недоступно.
- Публичный обзор и поиск публикаций, подписки и лента авторов.
- Черновики, публикации, одна фотография на запись, публичные профили и биографии.
- Лайки и плоские комментарии; владелец записи может удалять комментарии.
- Почтовые уведомления после подтверждения email и явного согласия. Отключение писем не меняет подписки и ленту.
- Русский и английский интерфейс, светлая, тёмная и системная темы, адаптация к телефону и широким экранам.

Компактная социальная лента использует простой системный шрифт без засечек.
Лента использует адаптивную masonry-сетку карточек, похожую на Pinterest.
На компьютере ширина основной области ограничена 3600 CSS px; имя автора,
необязательный заголовок и дата различаются по размеру и насыщенности текста. На планшете
аккаунт и создание записи представлены значками с доступными именами.
Подписи поиска визуально скрыты и остаются доступны скринридеру.
Основная тема — холодный графит с синим акцентом.
Закреплённый header плавно сжимается при прокрутке вниз и раскрывается вверх;
навигация, язык и тема остаются доступны. Настройка уменьшения движения отключает
переходы. В карточке после автора располагаются необязательная фотография,
необязательный заголовок и текст. Фотография сохраняет пропорции. На телефоне
карточки идут в одну колонку. В полном посте порядок остаётся прежним:
заголовок, фотография, текст; для записи без заголовка нет выдуманного видимого названия.
Лайки доступны прямо в ленте; ссылка «Комментарии» открывает обсуждение внутри
полного поста. Кнопка RU/EN меняет язык, значок темы открывает выбор светлой,
тёмной и системной темы. Сборщик и frontend-runtime не нужны.

На первом посещении выбирается первый поддерживаемый язык в списке предпочтений
браузера; если подходящего нет, используется английский. Ручной выбор сохраняется в браузере. После входа
используется язык аккаунта; если он ещё не выбран, интерфейс сохраняет текущий
язык. Тема сохраняется только в этом браузере, системная следует настройке ОС.
По умолчанию используется более мягкая графитовая тёмная тема; ранее сохранённый выбор
сохраняется. Боковой колонки авторов нет. Первая страница содержит до 24 записей;
следующая загружается кнопкой «Показать ещё», без автоматической загрузки при прокрутке.
Публикации, комментарии, биографии и имена не переводятся.

Текст записи обязателен. Заголовок необязателен, ограничен 200 символами;
пробелы по краям удаляются. При создании заголовок можно не передавать или
передать пустую строку. При обновлении отсутствие поля сохраняет заголовок,
а пустая строка очищает его; `null` не допускается. Существующие заголовки
сохраняются. Новая миграция не нужна. Для записи без заголовка почтовое
уведомление использует первые 80 символов текста с нормализованными пробелами.

Загруженная фотография открывается в модальном просмотрщике с сохранением пропорций.
Кнопка закрытия, Escape или нажатие на фон закрывают просмотр; фокус возвращается
к кнопке фотографии. При ошибке загрузки вместо активной кнопки показывается
сообщение. Поддержка видео отложена.

## Запуск на Linux

Нужны Python 3.14 и Docker Compose либо Podman.
Контейнеры, база и сервисы запускаются на выбранном Linux-сервере.

```bash
git clone https://github.com/wsersigma228/krug.git
cd krug
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt -c constraints.txt
cp .env.example .env
```

Укажи уникальный `SECRET_KEY`, надёжный пароль базы и правильный `PUBLIC_APP_URL`.
Параметры `DB_USER`, `DB_PASSWORD`, `DB_NAME` должны соответствовать `DATABASE_URL`.
Для пароля базы удобно использовать hex, чтобы избежать специальных символов URL:

```bash
.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(48))'
.venv/bin/python -c 'import secrets; print(secrets.token_hex(32))'
./scripts/start --dev-mail
```

Интерфейс: `http://localhost:8000/app`, API: `http://localhost:8000/docs`,
тестовая почта Mailpit: `http://localhost:8025`. Для внешнего SMTP настрой `.env`
и запускай `./scripts/start` без `--dev-mail`. Mailpit не отправляет письма наружу.
Скрипт собирает образ, останавливает сервисы приложения, проверяет зависимости,
применяет миграции новым кодом и запускает web/worker/beat с проверкой состояния.
База и фотографии сохраняются в volumes. Изменение `.env` не меняет пароль уже
существующего пользователя PostgreSQL.

При доступе с Windows можно пробросить порты:

```powershell
ssh -N -L 8000:127.0.0.1:8000 -L 8025:127.0.0.1:8025 app-host
```

## Язык аккаунта и письма

`POST /users` принимает необязательный `language: "ru" | "en"`.
`GET /me` возвращает язык, `PATCH /me/language` сохраняет `{"language":"ru"}`
или `{"language":"en"}`. Миграция `a75e9b024138` добавляет nullable-колонку
с ограничением ru/en; старые аккаунты остаются без выбора. Публичный профиль
не раскрывает настройку языка.

Служебные письма и уведомления используют актуальный язык получателя при отправке;
для аккаунтов без выбора используется английский. Заголовки публикаций остаются
исходными. Служебная ссылка для выбранного языка выглядит как
`/verify-email?lang=ru#token=...`: язык виден серверу, секрет остаётся во fragment.
Открытие ссылки не расходует токен — требуется действие в форме.

Подтверждение email действует 60 минут, сброс пароля — 30 минут. Повторный запрос
отменяет прежние ссылки этого типа. Выход и сброс пароля отзывают все сессии.
Уведомления о публикациях выключены по умолчанию; включаются через настройки
после подтверждения email. Повторное включение не восстанавливает отменённые письма.

## Поиск и страницы

`GET /explore` ищет публичные публикации всех авторов; `GET /posts` — собственные
записи после входа. Поиск по заголовку и содержимому использует PostgreSQL FTS.
`search_language=simple|russian|english` выбирается независимо от языка интерфейса:
`simple` ищет точные токены, русский и английский режимы учитывают основы слов.
Опечатки и произвольные части слов не поддерживаются.

Страницы возвращают `{items,next_cursor,has_more}`. Передавай курсор с теми же
фильтрами; `limit` допускает 1–100. Курсоры подписаны и не предоставляют доступ
к чужим черновикам. Страницы не являются снимком: изменения влияют на дальнейшую выдачу.

## Проверки

На сервере выполнения:

```bash
./scripts/compose up -d db redis
.venv/bin/python -m pytest -q
node --check frontend/app.js
node --check frontend/i18n.js
node scripts/check_i18n.cjs
.venv/bin/python -m scripts.smoke
.venv/bin/python -m scripts.smoke_accounts
```

Тестам нужна отдельная база **test_db**; её имя проверяется до подключения.
Для нестандартных портов/паролей настрой `TEST_DATABASE_URL`, а для smoke —
`APP_URL`, `MAILPIT_URL`, host-side `DATABASE_URL` и `REDIS_URL`.
`smoke_accounts` требует Mailpit. Проверки создают временные аккаунты и удаляют их.
Проверка браузера описана в [руководстве разработки](docs/development.md).
`node scripts/browser_locale.cjs` проверяет RU/EN, язык аккаунта, сохранность
пользовательского текста и темы на работающем приложении Fedora; требуется
Playwright из отдельной папки инструментов.
Наличие команд и CI-конфигурации не означает, что конкретный прогон уже прошёл.

## Ограничения и данные

Опубликованные записи и профили публичные. Приватные профили, видео, Stories,
личные сообщения, рекомендации, WebSockets и поиск с исправлением опечаток отложены.
Нет отдельного управления сессиями, панели модерации, автоматических резервных
копий и очистки потерянных файлов. При сбое после принятия SMTP письмо может
прийти повторно. Пропускная способность отправки не измерена.

Токены хранятся в sessionStorage вкладки; это не защита от XSS. Для публичного
размещения нужны HTTPS, корректный `PUBLIC_APP_URL`, SMTP и настройка прокси.
Фотографии перекодируются в JPEG с удалением метаданных, до 2560 × 2560;
это не архив исходников. Допускаются JPEG/PNG/статичный WebP до 8 МиБ и 16 Мп.

Резервируй PostgreSQL, volume `post_media` и приватный `.env`. Не используй
`down -v` или очистку volumes при обновлении. Mailpit не является резервной копией.
Смена `SECRET_KEY` отзывает JWT/курсоры и делает старые зашифрованные ссылки
в очереди писем недоступными для отправки.

Подробности: [API](docs/api.md), [разработка и развёртывание](docs/development.md),
[поиск на русском](docs/search.ru.md). Основной [README](README.md) содержит
подробное описание доставки, пагинации и эксплуатации.
